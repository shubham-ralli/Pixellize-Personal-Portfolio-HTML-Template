Pixellize Documentation

Thank you for purchasing Pixellize — Personal Portfolio HTML Template. This guide covers setup, structure and customization. If anything is unclear, reach out via the support section below.

Introduction

Pixellize is a modern, fully responsive one-page portfolio template built with clean HTML5, CSS3 (custom properties) and vanilla JavaScript — no build tools or frameworks required. It ships with dark/light modes, three accent color schemes, RTL support, a blog, and bonus pages.

Getting Started

No installation or compilation is needed. To preview locally:

  1. Unzip the downloaded package.
  2. Open index.html directly in a browser, or — recommended, so images and the contact form load correctly — run a tiny local server from the project root:
# Python 3
python3 -m http.server 8000

# or Node
npx serve .

Then visit http://localhost:8000.

Opening files with file:// can block the Google Fonts / contact form. Use a local server or upload to a host.

Colors & Theme

All colors are CSS custom properties defined at the top of assets/css/style.css under :root. To rebrand, change these values once:

:root {
  --accent:      #c4f135;  /* main brand color   */
  --accent-2:    #a3e635;  /* gradient partner   */
  --accent-deep: #4d7c0f;  /* accent text on light bg */
  --on-accent:   #10120a;  /* text on accent fills */
  --bg:          #0d0e12;  /* page background    */
  --text:        #e7e9ee;  /* body text          */
}

Dark / Light mode

The moon/sun button in the header toggles modes; the choice is saved in localStorage. Light-mode values live under :root[data-theme="light"].

Accent color schemes

The floating palette switcher (bottom-left) offers Lime, Blue and Purple — defined under :root[data-accent="blue"] / ["purple"]. Add your own scheme the same way, or delete the .style-switcher block from each page if you want a single fixed color.

RTL

Add dir="rtl" to the <html> tag (or use the switcher's RTL button) for right-to-left languages.

Text & Content

All text is plain HTML — edit it directly in each .html file. The brand name "Pixellize" appears in the header/footer as Pixel<span>lize</span> (the span is the accent-colored part). Names, stats, prices, FAQ and blog content are all inline and clearly labeled by section comments like <!-- ===== About ===== -->.

Images

Replace files in assets/images/ with your own, keeping the same filenames (or update the src in the HTML). Each <img> has width and height attributes for layout stability — update them to your image's real ratio if it differs.

The bundled demo photos are from Unsplash (see Credits). You may keep them for personal use, but replacing them with your own is recommended for commercial projects.

Fonts

Two Google Fonts are used, loaded in each page's <head>:

  • Space Grotesk — headings (--display)
  • Inter — body text (--sans)

Swap them by changing the Google Fonts <link> and the --display / --sans variables in the CSS.

Contact Form

The contact form posts to contact.php via AJAX. To make it live:

  1. Upload the template to a PHP-enabled host.
  2. Open contact.php and set $recipient to your email.
$recipient = 'you@yourdomain.com';

It includes a honeypot spam filter and header-injection protection. For guaranteed deliverability, switch mail() to SMTP (e.g. PHPMailer) — see the note at the bottom of the file.
